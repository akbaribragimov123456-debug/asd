AKBAR IBRAGIMOV — SHAXSIY SAYT

Fayllar:
- index.html — sahifa tuzilishi
- style.css — dizayn va pushti/oq ranglar
- script.js — tugmalar, modal oyna va mobil menyu

Qanday ochiladi:
1. ZIP faylni kompyuteringizga yuklab oling.
2. ZIP faylni Extract All / Arxivdan chiqarish orqali oching.
3. Ichidagi index.html faylini ikki marta bosing.
4. Sayt brauzerda ochiladi.

O‘zgartirish:
- Ism, yosh va matnlarni index.html faylidan o‘zgartirishingiz mumkin.
- Ranglar va dizayn style.css faylida.
- Tugmalarning ishlashi script.js faylida.

Eslatma: Google Fonts shriftini yuklash uchun internet kerak bo‘lishi mumkin. Saytning qolgan qismi internet bo‘lmasa ham ishlaydi.
